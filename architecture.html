Data Flow — Example: Inventory Page
1

User changes filter

FilterBar.vue updates useFilters.js singleton — selectedLocation, selectedCategory, etc.

2

Vue component reacts

Inventory.vue watches filter state via watchEffect, calls api.getInventory({ warehouse, category })

3

HTTP request

api.js builds GET /api/inventory?warehouse=Tokyo&category=sensors via Axios + URLSearchParams

4

FastAPI filters in-memory data

apply_filters() in main.py iterates over in-memory Python list, matching warehouse and category fields

5

Pydantic serialization

Filtered results validated against InventoryItem Pydantic model and returned as JSON array

6

Vue reactivity update

Response stored in items ref. Computed property filteredItems applies local search query. Template re-renders via v-for.
